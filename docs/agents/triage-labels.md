# Triage labels

The engineering skills speak in five canonical triage roles. This file maps them to this repo's labels.

| Canonical role | Label in this repo | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgement |
| `wontfix` | `wontfix` | Will not be actioned |

Additional repo labels used alongside triage: `blocked`, `priority:p0` … `priority:p2`, `type:*`, `area:*`, `phase:*`, `tier:*`.
